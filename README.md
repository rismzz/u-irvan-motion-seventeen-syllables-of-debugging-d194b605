One haiku about debugging, in the 5-7-5 syllable shape, at most 200 characters.
A judge model compares the haiku two at a time against the published brief:
the form must hold, the centre picture must be concrete, and the last line
must turn the poem.

> The cursor blinks once
> a log line scrolls past midnight
> Found: the bug was me

## Run it

```sh
python3 main.py
```

`main.py` writes the haiku to `/output/entry.txt` (77 characters, 3 lines,
syllable shape 5-7-5, verified by an assertion in the program itself).
Deterministic, no network, no randomness.
